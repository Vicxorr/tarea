# Impacto de las Tecnologías Web en la Sociedad y los Negocios

Proyecto académico estático desarrollado con HTML5 semántico y CSS3.

## Estructura
- `index.html`: página principal.
- `pages/`: páginas de sociedad, negocios, futuro y contacto.
- `css/styles.css`: hoja de estilos adaptable.
- `images/`: cinco ilustraciones SVG originales.
- `videos/`: video local de presentación y póster.
- `screenshots/`: vistas de referencia del sitio.

## Ejecutar
Abre `index.html` en un navegador. Para publicar, sube todos los archivos a un repositorio GitHub y activa GitHub Pages desde Settings > Pages > Deploy from a branch > main > /(root).

## Validación
Se recomienda validar cada archivo HTML en https://validator.w3.org/nu/ y corregir cualquier aviso que dependa del navegador o de la herramienta.

## Nota sobre el formulario
El formulario realiza validación HTML5 en el navegador. Al ser un sitio estático no envía ni almacena datos.
